# NHAPMON_CNPM_NHOM-24_QUAN_LY_LOP_HOC_THEM
Nền tảng kết nối và quản lý lịch học, học phí và điểm danh cho trung tâm hoặc các nhóm học thêm.
## Chức năng thông báo học phí

- Thông báo học phí đến phụ huynh.
- Cung cấp thông tin số tiền cần đóng.
- Thông báo thời hạn đóng học phí.
- Theo dõi tình trạng thanh toán học phí.
